# JogoFacefMago

Este projeto consiste em um jogo desenvolvido na plataforma Construct 3, com integração ao banco de dados Realtime Database do Firebase. O objetivo é permitir que o jogador insira seu nome e envie sua pontuação ao final da partida, armazenando essas informações no banco de dados e exibindo um ranking em tempo real.

---

## Funcionalidades

- Integração com o Firebase para envio e leitura de dados
- Interface de entrada de nome e envio de pontuação, visível após a morte do personagem
- Ranking exibido em tempo real, puxando os dados diretamente do Firebase
- Jogo com sprites e lógicas personalizadas

## Como abrir o projeto

1. Acesse [https://editor.construct.net](https://editor.construct.net)
2. Faça upload do arquivo `.c3p`
3. Execute o projeto clicando em "Play"
4. Para funcionamento completo, certifique-se de utilizar o seu próprio endpoint do Firebase Realtime Database
